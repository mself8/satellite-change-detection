# 인천국제공항 4단계 확장사업 전후(2017→2025) 변화탐지

AI기반 원격탐사(서울시립대) 기말 팀프로젝트 · 발표 12번 (3인 팀)

## 1. 개요
인천국제공항 4단계 건설사업(2017 착공 ~ 2024.12 완료) 전후를 **Sentinel-2 위성영상**과
**6개 분석기법**으로 변화탐지하고 정량 비교한 연구.

핵심 발견: 통념("확장 → 식생감소")과 달리 **안정육지에서 식생이 +8.8 km² 증가**.
2017 기준영상 자체가 공사 정점(나지) 상태였고, 이후 준공·조경녹화가 진행됐기 때문.
실제 신규 불투수화(확장 footprint)는 국지적(식생→비식생 3.0 km²). 단일지수 평균의
함정을 다기법 교차분석으로 규명.

## 4. 분석 기법 (7)
1. 트루컬러/위색 합성 — 시각적 전후
2. 분광지수 NDVI·NDBI·MNDWI + 차분영상(ΔNDVI, ΔNDBI)
3. 토지피복 분류(k-means 비지도, 3클래스) + 전이행렬
4. 변화벡터분석(CVA) — 6밴드 변화강도·유형 (Otsu 임계)
5. 주성분분석(PCA) — 차분영상 PCA 주변화축
6. Landsat 8/9 지표온도(LST) — 상대온도(anomaly) + 클래스별 온도대비

## 5. 핵심 수치 (안정육지 기준, 조위영향 배제)
- NDVI 평균 0.29 → 0.39 (+0.10), 식생화소 27% → 37%
- NDBI 평균 +0.02 → -0.03 (-0.055)
- 토지피복: 식생 30.5→39.3 km², 불투수·나지 36.4→27.8 km²
- 녹화(비식생→식생) 11.7 km² ≫ 신규개발(식생→비식생) 3.0 km² → 순 식생 +8.8 km²
- CVA 변화 10.2 km²(15%) / 차분PCA PC1 84%(ΔNDVI 상관 +0.56)
- LST: 절대평균 20→16°C(촬영일 기상차, 한계) / 불투수-식생 온도대비 +1.3→+1.9°C(녹화 열저감)
- 교차센서 검증: 2025 S2B·S2C NDVI 동일(0.392) → 식생증가는 실제

## 7. Landsat 지표온도(LST) — 포함 완료
초기엔 Microsoft Planetary Computer STAC의 일시적 504 장애로 보류됐으나, 자동 재시도
파이프라인이 PC 복구 후 데이터를 확보하여 **LST 슬라이드가 최종 발표자료에 포함**됨.
- 데이터: Landsat 8/9 Collection-2 Level-2 지표온도(ST_B10), 2017·2025 가을, Planetary Computer
- 절대 LST는 촬영일 기상차로 전반 하강(한계 명시) → **상대온도(anomaly)** 와
  **식생 vs 불투수 클래스별 온도대비**로 토지피복 열신호를 분리(기상오프셋에 강건)
- 재생성: `$PY src/fetch_lst.py && $PY src/05b_lst_figure.py && $PY src/06_build_pptx.py && $PY src/07_build_pdf.py`
